# Sentinel Nexus

Build a complete enterprise web platform for Sentinel Technologies.

Sentinel Technologies is a cybersecurity, network infrastructure, monitoring and technology services company.

The platform must look like a premium SaaS product used by enterprise customers.

TECH STACK:

* React
* TypeScript
* TailwindCSS
* shadcn/ui
* Responsive Design
* Dark Mode by default

VISUAL IDENTITY:

* Primary color: Deep Navy Blue (#03004C)
* Secondary colors: Blue gradients and subtle cyan accents
* White typography
* Modern cybersecurity aesthetic
* Inspired by Microsoft Security, CrowdStrike, Cisco Meraki, Datadog and Cloudflare

GENERAL REQUIREMENTS:

* Premium UI/UX
* Production-quality layout
* Fully responsive
* Modern animations
* Hover effects
* Smooth transitions
* Clean component architecture
* Dashboard-focused experience
